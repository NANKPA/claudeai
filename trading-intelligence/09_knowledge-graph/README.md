# Partition 09 — Knowledge Graph (graphify output)

Generated by `tools/build_graph.py`, which compiles every note and registry
into a graphify extraction and runs graphify's pipeline (Leiden communities,
god nodes, surprising connections, report, HTML, wiki).

| File | Use |
|---|---|
| `graph.html` | Interactive map. Open it in any browser (vis-network, no server). |
| `GRAPH_REPORT.md` | Plain-language report: communities, god nodes, surprising links, suggested questions |
| `graph.json` | Full graph (nodes, edges, communities). GraphRAG-ready; `graphify query` reads it. |
| `extraction.json` | The graphify extraction input (for audit / re-runs) |
| `BUILD_REPORT.md` | Our build stats: per-layer and per-kind counts, lineage depth, top hubs |
| `wiki/` | One article per community, crawlable by agents |

Rebuild after adding notes or scraped content: `python3 tools/build_graph.py`.
